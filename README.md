# The Burrow – downloads

The Burrow is een offline app om werelden te bouwen: pagina's die vanzelf naar
elkaar linken, kaarten, relaties en stambomen, en een tijdlijn met eigen kalenders.

Deze repository bevat alleen de installers. Download de nieuwste versie onder
**Releases**:

- **Windows:** `…_x64-setup.exe`
- **Linux:** `….AppImage` of `….deb`

Een geïnstalleerde app meldt zelf wanneer er een nieuwe versie is. Je werelden
blijven op je eigen computer en worden bij een update niet aangeraakt.
